# Auth email templates

Branded emails for Supabase Auth. `npm run provision` applies them automatically. To set them by hand,
open **Supabase → Authentication → Email Templates** and paste each file with its subject:

| Template | Subject | File |
|---|---|---|
| confirmation | Welcome to The Haven — confirm your email | `confirm-signup.html` |
| recovery | Reset your password for The Haven | `reset-password.html` |
| magic link | Your sign-in link for The Haven | `magic-link.html` |
| invite | You’re invited to The Haven | `invite.html` |
| email change | Confirm your new email for The Haven | `change-email.html` |

Generated by `scripts/admin/email-templates.mjs` — edit that, not these files.
